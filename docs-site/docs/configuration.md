# 配置与使用指南

### 核心技术体系

- **多格式解析器**：
  - EPUB：基于流式解包与虚拟滚动排版，完美还原章节脚注与矢量插图；
  - PDF：集成现代渲染器，支持高精度缩放与文本层提取；
  - TXT：智能检测字符集编码（UTF-8/GBK/Shift-JIS），自动按目录规则分析章节。
- **MiniSearch 离线全文索引**：
  书籍导入即在前端建立内存倒排索引，十万字大书支持毫秒级全文精确检索。
- **IndexedDB 本地书库**：
  阅读进度、自定义书签、划线高亮均保存在本地存储中，离线无网也能完整继续阅读。

## 生产部署建议

1. **环境变量保护**：切勿将包含真实密钥或 Token 的配置提交至版本库；
2. **优雅停机与超时**：建议将关键长任务的超时时限设置为合理范围，避免僵尸进程驻留；
3. **日志监控**：结合控制台输出建立定期检查机制，捕获潜在异常。
