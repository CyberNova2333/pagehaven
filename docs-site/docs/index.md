# 快速入门

PageHaven 是基于 Vue 3 与现代 Web 技术的**本地优先、纯离线运行的高颜值电子书库与阅读引擎**。

## 解决的核心痛点

- **痛点 1**：许多在线阅读器必须依赖云端账号，电子书上传后存在隐私泄露风险
- **痛点 2**：传统阅读器排版粗糙，缺少优质的字体渲染、代码高亮与日夜间双模式质感适配
- **痛点 3**：大体积图书全文检索速度缓慢，动辄出现卡死或白屏

---

## 环境准备

现代桌面/移动浏览器（Chrome 100+、Safari 16+、Edge、Firefox）。

---

## 快速安装与运行

```bash
# 1. 安装依赖并启动本地书库服务器
pnpm install
pnpm run dev

# 2. 浏览器直接访问
http://localhost:5173

# 3. 生产构建产物（可部署为静态站点）
pnpm run build
```
