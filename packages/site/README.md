# @gallery/site

[返回「页间 · Pagehaven」项目说明](../../README.md)

页间 · Pagehaven 的 Astro 静态站：作品 / 期 / 话页面、阅读器（每话一个 HTML，`#p12` 深链，文字层内嵌）、
搜索页（接线在 `@gallery/search`）。产物在仓库根 `dist/`（`DIST_DIR` 环境变量可覆盖）。

站点默认名称为「页间 · Pagehaven」，可在 `site.config.yaml` 修改。`site.logo` 统一导航、
favicon 与增强阅读器图标，默认书页 SVG；`site.tagline` 控制页脚文案，可留空。
外观由 `appearance` 控制：纸白（默认）、海蓝、暮紫主题，可选自定义主色与衬线／无衬线标题，
以及搜索、书架导航入口。三套主题均提供深色版本，共享语义色保持页面、表面、选区与阅读标注一致。
各页面只写自己的局部样式；样式随
`inlineStylesheets=always` 内联，dist 里不多出 CSS 文件；字体只用系统栈，不引外部字体请求。

只用 Web 标准 API（CLAUDE.md 铁律 1）：不 import Node 内置模块，Astro 页面的 frontmatter 也算。
数据与配置由构建脚本（`scripts/lib/site-generated.mjs`，Node）在 `astro build` 前写到
`src/generated/`（不入库），页面只 import 那些 JSON：

| 文件 | 内容 |
|---|---|
| `site-config.json` | 校验过的 `site.config.yaml`（`build:config` 与 `build:site` 都会写） |
| `gallery.json` | 作品 / 期 / 话 / 页与图片 key 的结构树，**不含台词框** |
| `text/<series>/<issue>/<chapter>.json` | 每话的台词框 `{ chapter, pages: [{ n, boxes: [{ i, x, y, w, h, t }] }] }`；只给有台词稿的话写，只写有框的页 |

`gallery.json` 里标了 `hasText` 的话，`text/` 下必须有对应分片：文字层开着而分片取不到时，阅读器页
**构建报错退出**（信息含该话 key），不会静默退化成「无文字层」——`pnpm run check` 只数 HTML，事后抓不到这种丢失。

```bash
pnpm run build:config   # 先生成 src/generated/site-config.json
pnpm run build:site     # = 写 gallery.json + text/ → astro build → 平台生成物 + GitHub Pages 基线文件
```

## 站点自定义

在仓库根运行 `pnpm run customize`，打开终端地址即可在浏览器中预览名称、Logo、页脚文案、
主题、主色、标题字体、导航入口及文字层／增强分页。设置只在点击保存后写入唯一的
`site.config.yaml`，备份原文件、保留注释，检测到并发修改时拒绝覆盖。旧配置无需显式
添加新字段即可使用默认外观；隐藏搜索或书架导航入口不会删除对应路由或浏览器记录。
预览区可切换深浅配色，仅用于检查外观，不写入配置或影响读者已保存的偏好。

工具是维护期间的临时服务，不进入静态产物。Codespaces 转发端口保持私有，并保留终端
地址片段中的访问令牌。Logo 支持 HTTPS 图片地址或站内 SVG 路径，暂不上传图片；
PNG、JPEG、WebP 等图片仍放 CDN，不进入 `dist`。保存后重新构建、检查并手动发布，
设置才对全部访客生效，正式站点不提供配置写接口。用完停止命令即可。

## 深浅配色

导航提供浅色、深色和跟随系统三种模式，默认跟随系统。读者的选择以
`pagehaven:color-scheme` 保存到当前站点的浏览器存储，取值为 `light` / `dark` / `system`；
存储受限时只在当前页保留并提示。跨标签页和页面恢复时同步已保存的选择，系统变化只在
跟随系统模式下改变实际配色。它是个人界面偏好，不写入 `site.config.yaml`，也不进入
书架、进度、页收藏、备注四类阅读数据备份。

`Base.astro` 在正文显示前运行小型内联引导，读取已保存的偏好，避免深色选择在打开页面时
先显示浅色。实际样式由构建期生成的深浅语义变量与 `prefers-color-scheme` CSS 共同控制；
关闭 JavaScript 时仍跟随系统，手动控件保持隐藏。书架、搜索和阅读控件共用语义色，
增强分页通过组件公开接口同步深浅模式，不重建阅读器或改变进度、书签。漫画图像不反色。
三平台运行同一份静态 HTML/CSS/浏览器模块，不新增服务端接口、配置字段或发布步骤。

## 页面

| 路由 | 文件 | 说明 |
|---|---|---|
| `/` | `pages/index.astro` | 作品列表（模型顺序：sort 再 title），检索入口 |
| `/<series>/` | `pages/[series]/index.astro` | 期列表：number、title、published、话数 |
| `/<series>/<issue>/` | `pages/[series]/[issue]/index.astro` | 话列表：number、title、页数、「有台词」（只在 `features.text_layer` 开时标——flag 关了阅读器没有文字层，列表不该还承诺） |
| `/<series>/<issue>/<chapter>/` | `pages/[series]/[issue]/[chapter]/index.astro` | 阅读器，见下 |
| `/search/` | `pages/search/index.astro` | 检索页壳；逻辑由 `packages/search` 接入 |
| `/library/` | `pages/library/index.astro` | 个人书架、页码书签与阅读备份；收藏、筛选、继续阅读及导入预览，noindex |
| `/404.html` | `pages/404.astro` | noindex |

外壳 `layouts/Base.astro`：`lang` 取 `site.lang`，页面标题使用 `site.title`，提供 viewport、
深浅主题、书页图标与共享内联 CSS。正式页面输出 canonical（`https://<site.domain>` + 路径）
和 `og:title`；书架、404 与预览页面使用 `noindex`，不输出 canonical。导航与页脚可按外观设置隐藏搜索、书架入口，页面与已有数据仍保留。不用 UI 框架。
共用的纯函数（图片 URL、百分比坐标、框样式、切源的域名替换）在 `lib/gallery.js`，lint 管得到，
单测在 `test/gallery.test.js`；流水线级的构建测试在 `scripts/test/site-build.test.mjs`。

默认模板没有作品时，首页仍显示站点名称和明确的空目录提示。搜索页分别提示「没有作品」
或「已有作品但尚未收录台词」，两种情况均不下载检索库。

作品 id 不能是 `search` `library` `api` `index` `series` `404` `cname`——它们是站点固定路由或固定文件，
Astro 会静默让静态路由赢；`scripts/lib/site-generated.mjs` 在构建时拦。

## 个人书架

作品页支持加入、移出书架，默认“想读”；“想读／在读／已读”由读者手动调整，翻页不自动
改变状态。`/library/` 按状态筛选、按作品名搜索，显示当前目录仍有效的最新阅读位置，继续
阅读链接复用 `#p<n>`。未读作品可从第一话开始，暂无章节的作品也可收藏，但不提供阅读链接。
移出书架只移除收藏，不清除阅读进度。

书架默认按“最近更新书架”排列，可切换为“最近阅读”。后者优先显示已有进度的收藏作品，
再按进度时间倒序；同时间按书架更新时间和目录顺序稳定排列，没有进度的作品放在后面。
排序和搜索仅使用当前页面缓存，不写入状态或排序偏好。

“阅读数据概览”复用书架和页书签刷新后的缓存，通过 `onSummary` 向
`lib/reading-overview.js` 提供五项总数：当前目录中收藏作品、有进度作品、有进度章节、
有效页书签和带文字备注书签。总数不随搜索、状态或作品筛选、展开数量变化，也不新增存储
读取。书签备注去除首尾空白后非空才计数，独立备注与编辑框草稿不计入。
概览等两类摘要就绪后显示；存储读写受限时提示可能不完整，含本页临时修改时提示尚未保存，
不把这些数字称为已完整落盘数据。备份导入后清空旧摘要并随重挂更新。

统计按页面已有恢复规则处理旧记录，例如非法页码可回第一页；备份导出则有独立校验，
还可保留目录外的合法记录，所以概览不等同备份的精确条数。这里只展示当前目录可显示
的记录，不修改、迁移或清理原数据。摘要回调异常不会中断书架、书签或备份保护。

独立的“最近阅读”区按章节展示最后一次已保存的位置，作品无需加入书架。它只扫描当前
目录中的 `gallery:progress:<chapter key>`，与书架恢复共用一次快照；标题、链接与页数取
当前目录，旧页码约束到现存范围，不清理未知章节或损坏记录。每章只有一条，不是逐次
访问流水；同时间按目录后章优先，时间缺失或不能格式化时显示“阅读时间未记录”。

历史按作品、作者、期名或章节名搜索，初始显示 20 话，“显示更多阅读记录”每次增加 20 话
并聚焦新条目。搜索和展开不重扫存储；相关跨标签记录变化、页面恢复、窗口重新获得焦点
以及“刷新记录”会重新读取。外部刷新保留章节焦点，必要时扩大显示范围；已在屏内的焦点
保持可见，离屏焦点不强制跳回。读取失败单独提示结果可能不完整，允许恢复读取后重试。
导入备份后复用现有重挂流程刷新历史，书架未保存修改和书签编辑保护继续适用。
每次刷新仍遍历当前章节目录，但相关跨标签事件由 `lib/storage-refresh.js` 合并：从首个事件
开始等待默认 50ms，窗口内后续事件不延期，因此持续更新也会按窗口刷新。浏览器后台节流
可能延迟实际执行；回到窗口、恢复页面或手动刷新会同步读取最新记录并取消待执行任务。
本页用户操作仍立即更新，销毁重挂时取消旧任务，不会覆盖书签编辑草稿或丢弃未保存状态。
书架和完整目录使用当前目录的键集合筛选事件，无关章节不排队；关闭目录会取消等待刷新。

每个作品单独使用 `localStorage` 键 `gallery:library:<seriesId>`，值为
`{ version: 1, status: "want" | "reading" | "read", updatedAt }`。页面只在读者操作时写入；
坏记录和已从目录移除的作品仅过滤显示，不自动清理。最新阅读位置只读已有
`gallery:progress:<chapter key>`，以当前章节 URL、标题与页数为准，不迁移旧记录。

数据限于当前浏览器与当前站点，没有账号同步；可通过下文的备份与恢复手动迁移，清除站点
数据、更换域名不会自动恢复。存储访问或写入被拒绝时，修改留在当前页面内存中，并明确提示只能在当前页面临时
保留。无 JavaScript 时保留站点目录入口，个人书架需要 JavaScript。书架页带 `noindex` 且不进
sitemap；功能运行于三平台共同的纯静态基线，不需要服务端接口或平台配置。

书架与页码书签有未保存修改时，即使失败删除的条目已从列表隐藏，页面仍显示“重试保存”
和“放弃未保存修改”入口。重试仅处理剩余失败项，保留原更新时间；放弃只清除本页临时意图，
重新读取已保存记录，不回写磁盘。书签备注仍在编辑时，需先保存或取消草稿。处理完成后解除
相应的备份阻止状态；其他类别仍有未保存修改时，备份保护继续生效。
书签重试会核对该页的成员与备注上下文；其他窗口已修改同页时，提示冲突并保留未保存状态，
不将旧备注操作写入新的收藏状态。可放弃未保存修改后核对最新记录，再明确编辑。

## 页码书签

普通阅读器和增强分页共用每话的页收藏。在阅读器中收藏当前页、添加或修改最多 200 字符
的备注；双页模式以页码框显示的当前页为目标。编辑区明确显示目标页，编辑期间翻页不会
改变该目标，也不会自动保存；由读者明确保存或取消。

书架页的页码书签区按作品筛选，集中显示当前目录仍有效的书签，链接到对应 `#p<n>`，
支持修改备注和移除。作品无需加入书架；移出作品书架不删除页书签。旧目录或越界页的
记录只在显示时过滤，不因打开页面而清理，阅读进度也不因读取书签而改变。

“查找书签”通过 `#bookmark-search` 搜索备注、作品名、作者、期名或章节名，可与作品筛选
组合。输入去除首尾空白后做 `NFKC` 规范化和英文小写转换，以连续子串匹配；空查询显示
该作品筛选下的全部书签。每次显示 50 条，“显示更多书签”继续增加 50 条；更换关键词或
作品时回到首批。查询与展开复用刷新时生成的搜索文本缓存，不额外读取存储或发送请求，
也不保存关键词偏好；阅读数据概览仍统计筛选前的总量。

编辑中的备注草稿不参与匹配，明确保存后才按新备注重新匹配；因关键词不再匹配而移出结果时，
关闭编辑器并将焦点返回搜索框。外部存储刷新保留当前查询和草稿，按最新记录更新搜索缓存；写入受限
时，已明确保存但仅留在本页的临时备注也参与匹配，原有未保存提示与备份保护保持有效。

收藏成员沿用 `gallery:favorites:<chapter key>` 的 JSON 字符串数组，成员为
`<chapter key>/p<n>`，增强阅读器已有记录无需迁移。备注独立保存在
`gallery:bookmark-note:<chapter key>/p<n>`，值为 `{ version: 1, note, updatedAt }`。
备注上限按 JavaScript 字符串长度与输入框 `maxlength=200` 一致；按纯文本显示。
普通与增强阅读器在同一页共享存储实例，书签修改同步更新，恢复收藏不会触发回写。

显示集合与完整保存集合分开：当前目录外或越界的合法收藏继续保留，编辑一页的备注不会
清理其他页。增强分页按上次同步的集合计算本次用户增删，再与最新存储合并，避免用旧快照
删除另一标签页新增的页与备注。阅读器取当前页备注和收藏 ID 时分别读取，跨标签事件沿用
50ms 合并窗口；翻页及明确的用户操作仍同步更新，销毁时取消排队任务。

书签、备注仍限当前站点的当前浏览器，无账号同步，可通过备份文件手动迁移。写入或删除受限时保留
当前页面中的临时结果并显示提示。没有 JavaScript 时漫画和原生页锚点仍可阅读，书签
操作保持隐藏。书签集中在现有 `noindex` 的书架页，不新增公开索引页面或平台配置。
翻页与进度核心继续内联；书签代码以同源模块共享，避免在每话重复内嵌同一套存储逻辑。
构建回归检查阅读器模块的实际依赖图，默认不加载检索执行器或增强分页。

## 阅读数据备份与恢复

在 `/library/` 的“备份与恢复”导出 JSON，或选择已有文件、核对导入预览后确认恢复。
文件只包含已成功保存的书架状态、进度、页收藏和备注；不包含图片、台词库、站点配置或
其他浏览器存储。存在本页临时修改或正在编辑的备注时，先保存或取消编辑再迁移。

备份格式由 `lib/reading-backup.js` 校验，标记为 `pagehaven-reading-backup`，版本为 `1`，
包含创建时间及 `library`、`progress`、`bookmarks`、`notes` 四组记录。上限为 5 MiB 与
20,000 条逻辑记录，收藏按页计数；拒绝未知字段、重复标识、非法页码或超过 200 字符的
备注。导出只扫描既有阅读数据键，跳过并报告损坏记录，读取失败不提供不完整的成功备份。

默认合并页收藏并保留本机已有状态、进度及备注；明确选择使用备份后才覆盖相同项目，
不删除文件未包含的记录。合法但未匹配当前目录的记录仍保留，展示由当前目录过滤；
独立备注不会创建收藏。进度链接按章节标识重建，标题取当前目录，不信任文件中的链接。
预览不写存储，确认前及写入过程中核对原值；发现变化就拒绝继续并要求重新预览。

多项浏览器存储写入不具备事务保证。失败时逆序尝试恢复本次写入，但只恢复仍等于本次
写入值的键，避免覆盖其他窗口的后续修改；恢复不完整时明确提示，不声称整体成功。
成功或部分写入后更新当前书架显示，其他标签页沿用原生存储事件同步。
所有文件处理都在浏览器完成，不上传、不新增路由、服务端接口、平台配置或公开索引。

## 阅读器

阅读器恢复旧进度时，非安全整数页码回到第一页，正常整数仍限制在现有页数内；明确指向其他
章节的记录不用于恢复，没有地址字段的旧整数记录继续兼容。翻页桥接入口采用同样的整数
检查，避免小数或非有限值造成空白页、长条恢复异常及后续无法保存进度。

- **可选增强分页**：`features.comimi_reader` 默认关闭；开启后阅读设置提供「增强分页」，由读者自行勾选。
  按需加载同源分页组件，使用原站的 `#p<n>`、每话页码和 `gallery:progress:<chapter key>`，
  不再建立另一套进度数据库。长条、显示文字、`#p<n>b<i>` 台词定位继续走标准阅读器；
  关闭选项或组件加载失败会退回标准阅读器。无 JavaScript 时所有图片和文字仍完整可读。
  页收藏与普通阅读器共用 `gallery:favorites:<chapter key>`，备注使用独立页键，与阅读进度分开；
  存储不可用时仅保留当前页面中的临时结果，详见「页码书签」。
  分享面板沿用站点页码深链，并在外部翻页后同步更新。
  依赖固定版本并随站点构建，不运行时访问第三方脚本 CDN；许可随产物放在 `licenses/comimi.txt`。
  启动、菜单、加载与错误状态统一使用 `site.logo`（默认站点 favicon）；说明页名称跟随 `site.title`，
  页收藏与说明文案使用「页码书签」「阅读器说明」。说明页保留第三方完整 MIT 许可入口，
  原版权与许可声明原样分发；依赖包名与技术字段保持不变。
  功能开关关闭的页面不加载增强入口，部署目标和响应头不变。
- **每话恰好一个 HTML**：全部页的 `<img src=webp loading="lazy" width height alt>` 都在这一份里，
  URL = `https://<images.hosts[0]>/<key>`。
- **文字层**（`features.text_layer` 为真时输出）：每页一个按 w/h 设 `aspect-ratio` 的定位容器，
  每个框一个绝对定位、透明背景、透明字色、可选中的 `<span class="box" id="p<n>b<i>">`，
  left/top/width/height 用百分比；w=h=0 的点标签画成一个小圆点（`.box.dot`），文本仍可选中。
  文本是普通 DOM 文本，爬虫可见。「显示文字」勾选框把文字层变成可见（`.reader.show-text`）。
- **渐进增强**：初始 DOM 全部页纵向可见；页尾内联脚本一跑，`#reader` 加 `.js`，
  按保存的阅读模式接管（首次默认单页）。
  没有 JS：全部页可读、`#p<n>` 是原生锚点、`#p<n>b<i>` 靠 `:target` 高亮。
- **翻页与阅读模式**：单页 / 长条 / 双页（宽屏两列，视口不超过 48rem 时同一跨页上下排列）；
  方向可切左→右 / 右→左，右→左时跨页的起始页放在右边。左右键、图片点击与滑动按方向映射；
  「上一页 / 下一页」和空格始终按章节顺序。按钮获得焦点时保留其原生键盘操作。
  支持全屏、亮度、页码跳转，f（全屏）、t（目录）、Esc 快捷键。
  亮度过滤仅作用于阅读画面，站点目录和设置保持清晰，并相对视口定位；面板内操作不会翻动背景漫画。
- **进度与目录**：每话读到第几页写 `localStorage`（`gallery:progress:<chapter key>`），
  没有 hash 时自动恢复；长条模式按视口上部的可见页保存，恢复时滚到该页，图片仍由原生 lazy
  按需加载。恢复先等文档解析和布局完成，定位期间不让滚动事件覆盖保存页码。
  滚动按动画帧合并、仅跨页时写存储，离开页面前再同步一次。首页「继续阅读」与
  作品页「继续阅读」读同一份记录。两页都精确匹配当前章节 URL，标题和页数以当前目录为准，
  旧页码限制到现存页范围；坏记录与存储访问失败不影响页面，也不删除旧记录。
- **按需目录**：每话只内嵌作品 / 本期目录链接与当前章标记，首次打开侧栏时加载
  `/index/<series>.json`，成功后在本页复用；并发打开只发一次请求。支持章节筛选、当前章定位，
  请求超时、失败或目录内容不匹配时提供重试与静态目录链接。无 JS 仍能通过上下话和目录导航。
  打开前不会取完整索引，也不把全作品目录重复嵌入每一话。
  目录打开后只读已有 `gallery:progress:<chapter key>`，显示“暂无进度”“读至第 N / M 页”
  或“已到末页”，有进度的链接带 `#p<n>`；URL 和页数取当前索引，旧页码约束在现存页范围。
  文字条件与“有进度／暂无进度”可组合筛选，“定位当前章”清空两类条件并定位当前章。
  每页最多渲染 100 话，结果超过一页时提供“上一组／下一组”和组数提示。首次打开定位当前章
  所在组；再次打开只在当前筛选结果中定位。改变筛选从第一组开始，“定位当前章”清空筛选，
  可跨组恢复当前章并聚焦链接。例如 250 话中的第 201 话位于第 3 组，该组显示最后 50 话。
  “章节顺序”默认正序，倒序跨期反转整个筛选结果后再分组，按索引中的章节先后排列，不按
  发布时间推断顺序。切换回第一组并保留筛选；定位当前章和输入组号沿用所选顺序。关闭目录
  再打开保留当前页面的选择，进入新页面恢复正序；排序不写阅读记录或阅读备份。
  结果超过一组时，“跳至组”接受当前筛选范围内的整数，点击“跳转”或按 Enter 直接进入指定组，
  并聚焦第一话。例如两万话可直接输入 `200` 进入最后一组；小数、负数、科学计数法和越界值
  会提示错误并保留原组。编辑中的组号在外部进度刷新时保留，合法上限随结果更新；前后翻组、
  改筛选或定位当前章会同步输入框并清除错误。单组和无结果时隐藏跳转入口。
  翻组不重复下载索引或读取进度；外部记录刷新保留所在组并收敛越界组数，仍在结果中的章节
  链接保持键盘焦点，矮屏定位使用实际可见范围，必要时只滚动目录内部的列表和外框。
  分页只减少浏览器中的目录节点，不拆分索引、不增加 HTML 或平台接口。
  当前章随阅读器实际页码更新，打开目录、页面恢复、窗口重新获得焦点及相关存储变化时
  更新个人进度；成功的目录索引继续复用。输入筛选只用内存结果，不重复读取浏览器存储。
  读取受限时提示进度不可用，目录链接仍可使用，不把读取失败当作“暂无进度”。浏览目录不
  写入、删除或迁移记录，也不会自动修改书架的“想读／在读／已读”状态；现有进度备份可复用。
- **图片状态与重试**：`lib/reader-images.js` 显示每页加载状态，失败时按配置依次尝试不同来源，
  耗尽后停止并提供“重试本页”。提示在图片框外，不遮挡台词和搜索高亮；重试不重置页码和阅读模式。
  模块挂载前已完成或失败的图片也会核对状态；保留原生懒加载，无 JS 时不显示脚本状态控件。
- **hash**：`#p<n>` 打开时定位到第 n 页，翻页时 `history.replaceState` 更新（不刷新、不堆历史）；
  `#p<n>b<i>` 额外高亮第 i 个框（`.hl`）并滚到它——检索结果按这个格式链过来。`hashchange` 也响应。
- **上一话 / 下一话**：模型的 `prev` / `next`（同作品内跨期），URL = `'/' + key + '/'`，
  `rel="prev"` / `rel="next"`，显示对方标题。
- **图片失败切源**：图片模块直接复用 `lib/gallery.js` 的 `swapHost`，只替换已配置来源的域名，
  按浏览器的主机名规则识别并去重配置中的大小写域名，保留不可变图片路径；正常加载不会访问
  备用源，手动重试从原始来源开始。
- **上一话 / 下一话的标题**在 `getStaticPaths` 里查一次表放进 props；frontmatter 每话跑一次，不在那里建全站查找表。
- 样式用 `is:global` + `.reader` 前缀而不是作用域样式：作用域样式会给每个台词框加一个
  `data-astro-cid` 属性，18 000 话下是几十 MB 的无用字节。
- `test/reader.test.js` 在 DOM 夹具中执行页面真实内联脚本，覆盖两种方向的按钮/键盘/点击/滑动、
  双页边界、长条恢复与滚动保存；随 `pnpm test` 运行。宽窄屏的实际两列排版仍需浏览器验收。

## 搜索页的约定 id

作品名、作者与标签过滤读取 `/index/series.json`，并发输入共用一次请求，成功结果在本页复用。
请求失败或 JSON 无效时显示重试提示，点击「过滤」或再次输入会重新请求；只有成功返回空数组才显示
「当前还没有作品」。加载期间修改输入时只显示最新条件的结果，旧请求结果或错误不会覆盖它。

| id | 元素 | 用途 |
|---|---|---|
| `search-form` | `<form method="get" action="/search/">` | 没有 JS 时提交只是把 `q` 留在 URL 里 |
| `search-input` | `<input name="q" type="search">` | 输入框 |
| `search-status` | `<p aria-live="polite">` | 「检索库加载中 / 暂不可用」等状态 |
| `search-results` | `<ol>` | 结果列表；每条链到 `/<series>/<issue>/<chapter>/#p<n>b<i>` |
| `search-config` | `<script type="application/json">` | `images.hosts`、`db.*`、`search.*`、`features.search_function` |
